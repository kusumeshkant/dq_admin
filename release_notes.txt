 CHANGES IN THIS BUILD
─────────────────────────────────────
• Staff Performance section — white screen + infinite
  scrolling fixed (data level + widget level)

  Data level:
  1. Reactivity miss — same RxList issue as Monthly Revenue.
     Obx was not registering a dependency on staffPerformance,
     so the section never rebuilt when data arrived.
     Fix: .toList() in the Obx callback.

  2. No sort order — staff appeared in arbitrary backend order.
     Fix: sorted by totalOrdersHandled descending in the
     controller so top performers appear first.

  Widget level:
  3. Infinite scroll — all staff cards rendered unconditionally
     in a Column. With 10-20+ staff the list grew to thousands
     of pixels, producing the "infinite scrolling" feeling.
     Fix: shows top 5 staff by default. A "Show X more" /
     "Show less" toggle at the bottom expands / collapses
     the full list.
