 CHANGES IN THIS BUILD
─────────────────────────────────────
• Responsive design system — full pass across all screens

  Core framework (new files in lib/src/core/):
  1. AppSpacing — spacing tokens (xs=4 … massive=56)
  2. AppSizes — icon/avatar/radius/button size tokens
  3. AppTypography — all text styles in one place
  4. AppResponsive — BuildContext extension with breakpoints,
     responsive<T>(), pagePadding, maxContentWidth, gridColumns
  5. ResponsiveLayout — typed widget switcher by DeviceType
  6. AppErrorWidget — standardised error+retry used on all screens
  7. AppLoadingWidget — standardised spinner used on all screens

  Shared widgets:
  8. AppGlassCard — radius/padding now uses AppSizes/AppSpacing tokens
  9. AppTheme — button/input radii now reference AppSizes tokens

  Screen updates (all 8 screens):
  10. Login — ConstrainedBox(maxWidth: 440) + centred for tablet;
      responsive horizontal padding
  11. Dashboard — AppLoadingWidget/AppErrorWidget; Quick Access grid
      adapts to 3-col on tablet; tokens throughout
  12. Stores — tablet shows 2-column GridView; AppLoadingWidget
  13. Products — tablet shows GridView; AppLoadingWidget;
      PopupMenu color uses AppTheme.surface (not hardcoded)
  14. Orders — dropdowns/chips use AppTheme.surface; AppLoadingWidget
  15. Staff — raw Color literals replaced with AppTheme tokens;
      responsive padding; AppLoadingWidget
  16. Store Detail — adaptive expandedHeight; responsive padding;
      AppLoadingWidget; tokens throughout
  17. Analytics — AppLoadingWidget/AppErrorWidget; responsive padding;
      AppTypography section headers
