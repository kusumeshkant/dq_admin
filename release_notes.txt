 CHANGES IN THIS BUILD
─────────────────────────────────────
• Monthly Revenue chart — widget-level rework

  Root cause (white screen / "infinite list"):
  Two problems in the chart widget:

  1. Reactivity miss — the Obx was passing the RxList
     reference directly without reading it, so GetX did
     not register a dependency. The chart never rebuilt
     when monthly data loaded; it stayed on its initial
     empty/stale state.
     Fix: .toList() called inside the Obx callback so
     GetX correctly tracks the list as a reactive read.

  2. Unconstrained bar layout — bars were built as
     Row + Expanded items. With Expanded inside Row
     inside a ListView, Flutter can pass unconstrained
     width down to the inner Column bars, causing a
     zero-width or white render in release mode.
     Fix: each bar is now a fixed-width SizedBox (28px)
     inside a SingleChildScrollView. The chart is
     horizontally scrollable, bars are always a
     readable size, and the layout is fully bounded.
